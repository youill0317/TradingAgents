# Security

Report a security problem privately through
[GitHub's security advisories](https://github.com/youill0317/TradingAgents/security/advisories/new),
not in an issue or a pull request.

Say what is affected, how to reproduce it, and what it lets someone do. Give the output of
`tradingagents --version`. Remove keys and anything private first.

This fork publishes no releases. Only the latest commit of its `claude/dazzling-fermat-ik4q5y` branch is
supported: a fix lands there.
